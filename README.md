# Chromium Code Gate

Расширение Chromium показывает экран входа и перенаправляет обычные веб-страницы на него, пока доступ не выдан. Панель владельца позволяет создать одноразовый код на 5 минут или отозвать доступ. Проверка сессии выполняется раз в 30 секунд.

## Развёртывание на Vercel

1. Создайте проект Vercel из этого GitHub-репозитория и оставьте корень проекта `.`.
2. Подключите Upstash Redis в Vercel Marketplace.
3. Добавьте переменные окружения `ADMIN_TOKEN` и `OPERATOR_TOKEN` (разные случайные значения от 24 символов), а также `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`, выданные Upstash.
4. Переразверните проект. `/api/health` должен отвечать `{ "ok": true }`.
5. Откройте `https://ВАШ-ДОМЕН/admin`, введите `ADMIN_TOKEN`, чтобы выдать код или закрыть доступ. Второму доверенному человеку передайте ссылку панели и `OPERATOR_TOKEN`.

Нужно использовать один Vercel project и одно Redis-хранилище для панели и расширения. Секреты не кладите в GitHub.

## Подключение расширения

В Chromium откройте `chrome://extensions`, включите режим разработчика и загрузите папку `extension`. Экран входа по умолчанию подключается к `https://olexiygey.vercel.app`. При каждом запуске браузера расширение удаляет сохранённый токен и блокирует восстановленные вкладки до ввода нового кода.

Чтобы расширение блокировало и окно Incognito, откройте его карточку на `chrome://extensions` и включите **«Разрешить использование в режиме инкогнито»**. Расширение использует отдельный процесс Incognito (`incognito: split`), но Chromium требует отдельного разрешения для запуска расширений в этом режиме. Пока разрешение выключено, gate показывает предупреждение.

Экран использует системный стек шрифтов. Предоставленная лицензия SF Pro ограничивает его использование макетами интерфейсов для программ под iOS, macOS и tvOS, поэтому файлы шрифта не встраиваются в Chromium-расширение.

## Локальный сервер

Для локального прототипа по-прежнему можно запустить `npm start` с `ADMIN_TOKEN`; он использует память процесса и не рассчитан на Vercel. Vercel Functions используют Redis через Upstash, объявленный в `api/`.

## Ограничения защиты

Обычное расширение не может запретить владельцу компьютера отключить или удалить его, запустить другой браузер или создать другой профиль. Чтобы полностью выключить Incognito в Windows, на управляемом компьютере нужно задать политику `IncognitoModeAvailability=1` для Chrome или Chromium. Для защиты от отключения расширение должно быть принудительно установлено политикой администратора из доверенного источника. Пользователь с правами локального администратора всё равно может изменить или удалить локальные политики.

Проверка кода ограничивает каждую выданную пару до 10 попыток; для новой серии попыток оператор должен выдать новый код.
