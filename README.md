# Chromium Code Gate

Расширение Chromium показывает экран входа и перенаправляет обычные веб-страницы на него, пока доступ не выдан. Панель владельца позволяет создать одноразовый код на 5 минут или отозвать доступ. Проверка сессии выполняется раз в 30 секунд.

## Развёртывание на Vercel

1. Создайте проект Vercel из этого GitHub-репозитория и оставьте корень проекта `.`.
2. Подключите Upstash Redis в Vercel Marketplace.
3. Добавьте переменные окружения `ADMIN_TOKEN` и `OPERATOR_TOKEN` (разные случайные значения от 24 символов), а также `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`, выданные Upstash.
4. Переразверните проект. `/api/health` должен отвечать `{ "ok": true }`.
5. Откройте `https://ВАШ-ДОМЕН/admin`, введите `ADMIN_TOKEN`, чтобы выдать код или закрыть доступ. Второму доверенному человеку передайте ссылку панели и `OPERATOR_TOKEN`.

Нужно использовать один Vercel project и одно Redis-хранилище для панели и расширения. Секреты не кладите в GitHub.

## Подключение расширения

В Chromium откройте `chrome://extensions`, включите режим разработчика и загрузите папку `extension`. В настройках экрана доступа укажите базовый HTTPS адрес Vercel, например `https://ваш-проект.vercel.app`.

На Apple системный стек использует SF Pro; на Windows страница использует системный шрифт. Файлы SF Pro не публикуются в репозитории, чтобы не перераспространять проприетарные шрифты.

## Локальный сервер

Для локального прототипа по-прежнему можно запустить `npm start` с `ADMIN_TOKEN`; он использует память процесса и не рассчитан на Vercel. Vercel Functions используют Redis через Upstash, объявленный в `api/`.

## Ограничения

Расширение может блокировать обычную навигацию и поиск, но пользователь с полным доступом к компьютеру может отключить расширение. Внутренние страницы Chromium этим способом не защищаются.
